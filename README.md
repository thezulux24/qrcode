# 🔳 QR Code Generator with Logo (Streamlit App)

Esta aplicación permite generar códigos QR personalizados directamente desde el navegador, con la opción de incluir un **logo centrado** en el código generado. Está construida usando **Streamlit** y la biblioteca **qrcode** de Python.

---

## 🚀 Funcionalidades

- ✅ Generación de códigos QR a partir de un enlace.
- 🖼️ Posibilidad de insertar un logo personalizado dentro del QR.
- 📥 Descarga del código QR generado en formato `.png`.
- 💻 Interfaz amigable desarrollada con Streamlit.

---

## 🛠️ Instalación

1. Clona este repositorio:

```bash
git clone https://github.com/thezulux24/qr_generator.git
cd qr_generator
```

2. Instala los requerimientos:

```bash
pip install -r requirements.txt
```

---

## ▶️ Ejecución

Antes de ejecutar asegúrate de estar en el entorno virtual (si usas uno), y luego ejecuta:

```bash
streamlit run main.py
```

## 🧪 Ejemplo de Uso

1. Ingresa un enlace en el campo de texto.
2. (Opcional) Sube una imagen `.png` o `.jpg` como logo.
3. Visualiza el QR generado en pantalla.
4. Descárgalo con un solo clic.
